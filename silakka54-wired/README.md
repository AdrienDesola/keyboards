# Silakka54 wired (Vial)

`silakka54.vil` is a Vial export refreshed from the board itself (read over VIA raw HID on 2026-10-11); it is the layout
that `../silakka54-wireless` reproduces. Re-export from Vial to refresh the file.

Layout on the board:

- **Base**: `` ` `` 1–5 · Tab QWERT · Ctrl/Esc ASDFG · Shift, Alt/Z, XCVB — 6–0 `\` · YUIOP Bspc · HJKL ; ' · NM , . RAlt// Shift.
  Thumbs: Meh, Cmd, Space (hold: Symbols) — Enter (hold: Nav), Cmd, empty.
- **Symbols** (hold Space): F1–F5 / F6–F11 on the number row, `! @ # $ %` on QWERT, `^ & * ( )` on ASDFG, `[ ] { }` on CVB, `= - [ ]` on YUIO, Bspc, F12 on `'`.
- **Nav** (hold Enter): arrows on HJKL, Home on Y, PgUp on Bspc, PgDn on `'`, `[ ]` on IO, Vol−/Vol+/Mute on WER, Rewind/FF/Stop/Play on ASDF.
